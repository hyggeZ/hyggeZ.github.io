四、派生数据类型

1. 数组

数组里的元素必须为同一类型。声明数组时，必须指定其长度或大小.

Go语言数组是值类型，而不是引用类型，传递为值传递。只支持正向索引。

Go
var array [3]int = [3]int {1, 2, 3}

2. 切片slice

声明后长度可变，切片变量本身在栈上占用24个字节，底层是三个字段组成的结构体

Go
type SliceHeader struct {
    Data uintptr // 8 字节：指向底层连续数组成员的指针
    Len  int     // 8 字节：当前切片已经存了多少个元素
    Cap  int     // 8 字节：当前底层数组总共能容纳多少个元素（容量）
}

len<cap 不扩容直接写，len==cap 触发扩容，整个搬到新地址，更新len和cap

Go
var list [ ]string
list = append(list, "aaa")
list = append(list, "知道")
list[1] = "不知道"//修改第2个元素

3. 映射map 无序键值对的集合

引用类型，本身是8字节指针，指向堆中的运行时结构体hmap

原理说明
map 变量（8 字节指针）→ hmap 结构体 → Buckets Array

单个 Bucket 内部：
tophash: [8 个哈希高 8 位]
keys:    [Key1, Key2, ..., Key8]
values:  [Val1, Val2, ..., Val8]
overflow: 指向溢出桶的指针（若超过 8 个元素）
Go
// 简化版的 Go 运行时 hmap 结构体
type hmap struct {
    count      int
    flags      uint8
    B          uint8
    noverflow  uint16
    hash0      uint32
    buckets    unsafe.Pointer
    oldbuckets unsafe.Pointer
    nevacuate  uintptr
    extra      *mapextra
}
Go
type bmap struct {
    tophash [8]uint8 // 存储 8 个 Key 的哈希值的高 8 位（用于快速定位）
    keys     [8]KeyType
    values   [8]ValueType
    overflow uintptr // 指向下一个溢出桶，用于解决哈希冲突
}
原理说明
读取过程：
1. 使用 hmap.hash0（哈希种子）配合哈希算法，将 Key 映射为 64 位哈希值。
2. 利用低位（Low bits）定位 buckets 数组中的桶。
3. 利用高位（High bits）在桶的 tophash[8] 中比较。
4. 对比完整 Key，匹配后通过偏移量取出 value。
5. 桶满时申请新桶，并由 overflow 指针连接。

key必须是基本数据类型，value可以是任意类型。用前必须初始化

初始化：（1）var userMap = map[int]string{ }

（2）var userMap = make(map[int]string)

Go
make用法m := make(map[string]int, size)最多只能接收两个参数
var userMap map[int]string = map[int]string{ 1: “张三”, 2: “李四” }
fmt.Printf(usrMap[1])// 输出 张三
value, ok := userMap[1]//用两个变量接收，第二个值bool类型，表示是否存在
