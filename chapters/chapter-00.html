语言结构

1. 结构

package main// 包声明import "fmt"// 引入包func main() {// 函数   /* 第一个程序 */// 注释   fmt.Println("Hello, World!")//语句}

2. 执行

（1）

Terminal
go mod init my_study

在根目录下运行，生成go.mod文件，用于管理当前模块的依赖和Go版本

（2）写代码并保存为hello.go

（3）

Terminal
go run hello.go

生成临时二进制文件并执行，执行后自动清理

（4）

Terminal
go build hello.go

生成hello.exe可执行文件
