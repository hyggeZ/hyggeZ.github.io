CHAPTER 05

五、语句

1. if语句

Go
if value, ok := myMap[1]; ok {
    // 找到了 key，value 此时可用
    fmt.Println(value)
} else {
    // 没找到 key，value 此时也可以用（是零值）
}
// 出了 else 的大括号，value 和 ok 无法访问

去掉圆括号，强制要求{}。if支持在条件判断前执行一个初始化语句，;隔开

中断式，卫语句最优

（1）分支预测，提前猜测if成立与否并加载缓存，面临预测失败清空流水线的硬件损耗惩罚

（2）短路求值，&&检测前面为假就跳否，||检测前面为真就跳是

2. switch语句

底层优化：（1）二分查找树，用于case数值多且分布稀疏

（2）跳转表，用于case值非常密集

每个case独立，执行完自动中断跳出，不需要写break。想继续要加fallthrough

允许一个case支持多个表达式，eg. case "Saturday", "Sunday":...

switch后面不接东西直接{}时（表示true），每个case可以写独立的布尔表达式。或者switch后的表达式也是bool类型时也可以

3. for循环

Go
for 初始化; 条件; 操作 {
    // 循环体
}

for { } // 死循环
for true { } // 死循环
for i := 1; true; i++ { } // 死循环

while循环

Go
i := 0
for i <= 100 {
    // ...
    i++
}

遍历切片

Go
var list = []string{"枫枫", "知道"}
for i := 0; i < len(list); i++ {
    fmt.Println(i, list[i])
}
for index, item := range list {
    fmt.Println(index, item)
}

遍历map

Go
var userMap = map[string]string{"name": "枫枫"}
for key, value := range userMap {
    fmt.Println(key, value)
}

变量是值的副本，改写不会影响原容器
