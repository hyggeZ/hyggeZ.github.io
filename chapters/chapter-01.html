一

变量声明（静态语言）

1. var关键字（类型后置）

（1）先定义，再赋值

Go
var name string
name = "aaa"

（2）定义+赋值

Go
var name string = "aaa"

（3）变量类型省略

Go
var name = "aaa"

2. 简短声明（只能用于局部变量）

Go
name := "aaa"

※ 注意：（1）局部变量定义必须使用，全局变量可以不用

（2）零值机制：变量定义时会被赋初值

3. 定义多个变量

Go
var name1, name2, name3 string // 定义多个变量

var a1, a2 = "aaa", "bbb" // 定义多个变量并赋值

a3, a4 := "aaa", "bbb" // 简短定义多个变量并赋值
Go
var (
name     string = "aaa"
userName        = "aaabbb"
)

4. 常量定义

Go
const name string = "aaa"

※ 首字母大写的标记可在包外访问，否则protected

※ { 不能单独放在一行
