二

输入输出

1. 输出：fmt包

（1）

Go
fmt.Print("Hello,") // 直接输出不换行

（2）

Go
fmt.Println("Hello!") // 末尾换行，传入多参数输出时中间会自动加空格

（3）

Go
fmt.Printf("Name: %s, Age: %d\n", name, age) // 格式化输出，占位符控制输出格式

（4）Sprint家族，将内容赋值给变量。常用于拼接不同类型的字符串，生成动态信息。

Go
msg := fmt.Sprintf("年龄是: %d", 18)
return fmt.Errorf("未成年禁止访问，当前年龄为: %d", age)

2. 输入：fmt包

fmt 的扫描函数在读取变量时，必须传入变量的指针（加上 &），以便修改变量的值。变量需要提前定义。

（1）

Go
fmt.Scan 读取以空格或换行分隔的值，直到填满所有接收参数

（2）

Go
fmt.Scanln 读取以空格分隔的值，但遇到换行符会立即停止

（3）

Go
fmt.Scanf 通过格式化模版读取输入
Go
_, err := fmt.Scanln(&name, &age)

返回值为成功读取的变量个数，读取中的错误。“_”可以把不用的变量丢掉。后面接：

Go
if err != nil {
    fmt.Println("输入有误，请重新输入！错误原因:", err)
    return
}

3. 占位符

（1）%d十进制整数

（2）%s字符串

（3）%t布尔值

（4）%f小数%.2f 两位小数

（5）%T类型fmt.Printf("%T\n", 3.14) // 输出: float64

（6）%v任意类型%+v 会打印结构体字段名%#v 详细打印（可用于空字符串，会显示””而不是空白）
