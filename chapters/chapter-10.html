2. map实现线程安全

（1）读写锁

Go
type SafeMap struct {
    sync.RWMutex
    data map[string]int
}
func (sm *SafeMap) Get(key string) int {
    sm.RLock()
    defer sm.RUnlock()
    return sm.data[key]
}
func (sm *SafeMap) Set(key string, val int) {
    sm.Lock()
    defer sm.Unlock()
    sm.data[key] = val
}

允许同时读，适用于读>写时

（2）sync.Map

内部包含一个只读的read内存块和负责写入的dirty内存块。读数据优先在read块里读，利用CPU硬件级的原子操作，不需要加锁。

Go
func main() {
    var m sync.Map
    m.Store("ZhengHao", 100)
    if val, ok := m.Load("ZhengHao"); ok {
        fmt.Println("拿到值：", val)
    }
    m.LoadOrStore("Tianjin", 2026)
    m.Delete("ZhengHao")
}

适用于读极多，写极少。各协程间读写不同key
