7. string的本质

（1）string的头结构

任何string变量声明时，都会在栈上分配16字节的固定空间，底层是一个包含两个字段的隐式结构体

Go
// 这就是 Go 运行时中 string 的本质形态
type StringHeader struct {
    Data uintptr // 8 字节：一个指针，指向真正存放字符数据的底层字节数组
    Len  int     // 8 字节：一个整数，记录字符串包含的字节长度
}
原理说明
栈内存（s 变量本体，固定 16 字节）
├── Data（底层数组指针）
└── Len（字节长度 = 5）
        ↓
只读数据段（分配在堆或只读内存区）
