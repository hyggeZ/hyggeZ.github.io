CHAPTER 08

八、接口

接口是一组仅包含方法名、参数、返回值的未具体实现的方法的集合。

Go语言的接口是非侵入式的，不需要声明承接了哪个接口，只需要把接口的方法全部实现

1. 接口语法：

Go
type Card interface {
    Deduct(amount int) // 需要定义名称 参数 返回值，但不写func关键字
}

2. 实现

Go
type StudentCard struct{ Balance int } // 实现者A
func (s *StudentCard) Deduct(amount int) { s.Balance -= amount } // A实现Deduct

type TeacherCard struct{ Balance int } // 实现者B
func (t *TeacherCard) Deduct(amount int) { t.Balance -= amount } // B实现Deduct

func DeviceProcessPayment(c Card, price int) { // 调用接口的函数
    c.Deduct(price) // 只要满足 Card 接口，就一定有 Deduct 方法，直接调用
    fmt.Println("扣款成功！")
}

func main() {
    stu := &StudentCard{Balance: 100} // 实现者A的实例
    tea := &TeacherCard{Balance: 500} // 实现者B的实例
    // 同一个函数，可以传入不同的结构体
    DeviceProcessPayment(stu, 15)
    DeviceProcessPayment(tea, 20)
}

3. 底层实现

对于 var c Card = &StudentCard{Balance: 100}

变量c在内存中占16字节，由两个8字节指针组成：

原理说明
变量 c 的 16 字节空间：
├── tab 指针（8 字节）：指向包含动态类型和方法表的只读内存区域
└── data 指针（8 字节）：指向具体的数据实体（&StudentCard{Balance: 100}）
原理说明
全局只读内存区：
接口类型：Card
真实类型：*main.StudentCard / *main.TeacherCard
方法表：StudentCard.Deduct / TeacherCard.Deduct

4. 类型断言

假设接口Cleaner实现了Clean()方法。Robot结构体实现了Clean() 和自己的Charge()。将Robot传入接口函数，自己的方法不可用。

Go
func DoJob(c Cleaner) {
    c.Clean()
    // 编译器拒绝编译：Cleaner 接口里没有定义 ChargeBattery 方法
    // c.ChargeBattery()
}

将c 还原成*Robot类型就叫类型断言

Go
func DoJob(c Cleaner) {
    c.Clean()
    if r, ok := c.(*Robot); ok {
        r.ChargeBattery()
    } else {
        fmt.Println("这里面装的根本不是机器人，别白费力气了")
    }
}

语法糖：

Go
func InspectInside(container any) {
    switch v := container.(type) {
        case int:
        fmt.Printf("这里面是个整数，翻倍：%d\n", v*2)
        case string:
        fmt.Printf("这里面是个字符串，长度：%d\n", len(v))
        case *Robot:
        v.ChargeBattery()
        default:
        fmt.Println("未知的神秘物种")
    }
}

5. 空接口

interface{} 或者 any

Go
func main() {
    var universe any = 42
    // fmt.Println(universe + 10) // 编译报错
    if realNum, ok := universe.(int); ok {
        fmt.Println(realNum + 10) // 输出：52
    }
}
