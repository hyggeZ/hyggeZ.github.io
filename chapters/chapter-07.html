CHAPTER 07

七、结构体与方法

1. 结构体

Go
type 结构体名称 struct {
    名称 类型 // 成员或属性
}

2. 方法 在func后加 (接收者)

（1）值接收者 (u User)

将原结构体的所有数据复制给一个新的临时变量，方法内部修改的值不会影响原结构体

（2）指针接收者 (u *User)

只复制了原结构体的地址给指针u，取值同样用“.”，可以修改原结构体

Go
type User struct {
    Name string
    Age  int
}

func (u User) UpdateAgeValue(newAge int) { u.Age = newAge }
func (u *User) UpdateAgePointer(newAge int) { u.Age = newAge }

语法糖：mainUser是普通结构体变量，不是指针，但能直接调用指针接收者方法。反之亦然，结构体指针也可以直接调用值接受者方法。

3. 结构体组合代替继承

Go
type People struct { // 父类
    Time string
}

func (p People) Info() { // 父类的方法
    fmt.Println("people ", p.Time)
}

type Student struct { // 子类
    People // 子类结构体包含匿名父类
    Name string
}

func main() {
    p := People{Time: "2026-7-19"}
    s := Student{
        People: p,
        Name: "aaa",
    }
    s.Info() // 子类可以调用父类方法
    fmt.Println(s.Time) // 将 s.People.Time 省略（名字不冲突前提下）
}

4. 结构体标签和JSON

（1）JSON文本：{"name": "aaa", "age": 18}

JSON字段通常是小写驼峰，但Go的结构体字段首字母必须大写才能被外面的包访问。为解决这个问题，创造了结构体标签。

（2）结构体标签

紧跟在字段类型后面、用反引号 ` 包裹。格式为 键:“值”，如果是给JSON库看的，键就是json。注意：冒号后不能有空格。

Go
type User struct {
    Name string `json:"name"`
    Age  int    `json:"age"`
}

`json:"-"` 忽略字段，`json:"age,omitempty"` 忽略空值
