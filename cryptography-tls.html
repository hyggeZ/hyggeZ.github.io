Diffie–Hellman 密钥交换

Client 与 Server 计算出相同的 Shared Secret

双方事先公开参数pg

Client

生成临时 SK:a、PK:A

将 A 发给 Server

A = ga mod pSclient = Ba mod p= (gb)a mod p
A⇄B

Server

生成临时 SK:b、PK:B

将 B 发给 Client

B = gb mod pSserver = Ab mod p= (ga)b mod p
计算结果相等Shared Secret↓HKDF 密钥派生
