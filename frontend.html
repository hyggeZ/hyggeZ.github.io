一DOM

DOM（Document Object Model，文档对象模型）是浏览器将 HTML 文档转换成的一组对象结构。JavaScript 不能直接修改磁盘上的 HTML 文件，因此浏览器创建 DOM，JavaScript 操作 DOM 对象后，浏览器再重新渲染页面。

可以把一个 HTML 元素理解成浏览器创建的 JavaScript 对象：

JavaScript
const heading = {
  tagName: "h1",
  id: "title",
  innerText: "Hello",
  children: []
};

document.getElementById("title"); // 返回一个 DOM 对象

浏览器执行 JavaScript 时会提供全局对象，例如 document 代表当前网页，window 代表浏览器窗口。访问 window 的属性时通常可以省略 window.。

DOM 不是 JavaScript 语言本身的一部分，而是浏览器提供的一套 API。

DOM 常用方法

方法带有 ()，属性则没有。

  • document.getElementById("id")根据 id 获取单个元素
  • document.querySelector("#app")使用 CSS 选择器获取第一个匹配元素
  • document.querySelectorAll(".card")获取所有匹配元素
  • document.createElement("div")创建一个新元素
  • box.appendChild(div)向父元素添加子元素
  • div.remove()删除当前元素

获取元素并绑定事件

HTML
<h1 id="title">你好</h1>
<button id="btn">修改</button>
JavaScript
const title = document.getElementById("title");
const btn = document.getElementById("btn");

btn.onclick = function () {
  title.innerHTML = "Hello";
};

二属性

1. HTML 常用属性

HTML 元素可以通过属性补充标识、样式、资源地址或事件行为，基本格式如下：

HTML
<tag 属性="值"></tag>
  • id元素的唯一标识，例如 <div id="app">
  • class元素分类，可让多个元素共享 CSS 样式
  • style直接在元素上书写 CSS
  • src资源地址，常用于图片和脚本
  • href链接地址，常用于 <a> 元素
  • value输入元素的初始值

事件既可以写在 HTML 属性中，也可以在 JavaScript 中绑定：

HTML
<button onclick="sayHello()">点击</button>

2. DOM 对象属性

  • innerHTML读取或修改 HTML 内容，会解析其中的标签
  • innerText读取或修改可见纯文本，不解析 HTML
  • textContent读取文本内容，包含隐藏元素中的文本
  • value读取或修改输入框的当前值
  • style修改行内样式，例如 box.style.color = "red"
  • className读取或替换元素的完整 class 字符串

3. 常用事件

  • click鼠标点击
  • input输入内容发生变化
  • change表单元素的值确认改变
  • submit表单提交
  • mouseenter / mouseleave鼠标进入或离开元素
  • keydown / keyup键盘按下或松开
JavaScript
input.addEventListener("input", function () {
  console.log(input.value);
});

form.addEventListener("submit", function (event) {
  event.preventDefault();
});

三三件套语法补漏

1. CSS 选择器

HTML
<div class="box">
  <p id="title" class="text">Hello</p>
</div>
CSS
/* 标签选择器 */
p { }

/* id 选择器 */
#title { }

/* class 选择器 */
.text { }

/* 后代选择器 */
.box p { }

/* 子元素选择器 */
.box > p { }

/* 多个选择器 */
h1, p { }

2. JavaScript 基础

  • let / const主要的变量声明方式；JavaScript 是动态类型语言
  • number string boolean undefined null bigint symbol基本数据类型
  • [1, 2, 3, 4]数组，本质上是 Array 对象
  • { name: "Tom", age: 20 }对象，可用点语法或方括号访问属性
  • function add(a, b) { return a + b; }普通函数
  • const add = (a, b) => a + b;箭头函数
  • === / !==严格相等与严格不等

模板字符串

模板字符串使用反引号包裹，并通过 ${表达式} 在字符串中嵌入 JavaScript 表达式。

JavaScript
const name = "Tom";
const age = 20;
const text = `My name is ${name}, age is ${age}`;
